\section{NLI in grounding and relation classification}\label{section:results-nli-in-grounding-and-relation-classification}

Natural language inference (NLI) is used in two downstream components, and both of them use the same NLI model, \texttt{pritamdeka/PubMedBERT-MNLI-MedNLI}~\parencite{gu2021biomedbert, williams2018mnli, romanov2018mednli}. The first component is the grounding filter, which checks whether a claim is entailed by its cited source paragraph; the second component is the relation classifier, which labels claim pairs as supporting, contradicting, or unrelated. This section evaluates both of these components, and answers RQ4.

\medskip{}

\textbf{Grounding filter (E03).} The grounding filter takes the cited source paragraph for each extracted claim, computes an entailment score, and drops the findings below a certain threshold. A threshold sweep is run over the MAP findings that were emitted by the pipeline using the configuration frozen after calibration, and the survivors are scored against silver. The distribution of the grounding entailment scores is shown in Figure~\ref{fig:results-grounding-hist}.

The sweep shows that grounding and silver-agreement are largely independent. The highest strict-F1 ($0.7160$) is reached with the grounding filter turned off (Section~\ref{section:results-cost-quality-comparison}). Raising the threshold barely changes precision (filter-off $0.872$ vs $0.875$) but reduces recall. Therefore, the filter functions as a source-faithfulness guard, rather than as a strict-F1 optimizer. This is clearest at the pinned $0.5$ threshold: among the roughly $16\%$ of findings the filter removes ($371$ of $2294$), about $86\%$ agree with the Opus-silver. In other words, a finding can match the Opus silver, while its claim fails to be entailed by its evidence paragraph.

Because strict-F1 measures agreement with the Opus labeler rather than source-faithfulness, the pipeline accepts a six-point strict-F1 decrease ($0.716 \rightarrow 0.652$) to ensure that every retained claim is supported by the evidence it cites. This trade is deliberately chosen for the clinical-knowledge base.

\medskip{}

\textbf{Relation classifier (E13).} The pipeline output with the frozen configuration contains too few real contradictions to estimate per-class accuracy. Therefore, the relation classifier is evaluated on a synthetic, class-balanced dataset generated by Claude Opus, with 100 supporting, 100 contradicting and 100 unrelated claim pairs. 

The NLI relation-classifier has two modes: \texttt{predicate\_only} and \texttt{scope\_aware}. \texttt{predicate\_only} only considers the claim text for each claim; \texttt{scope\_aware} prepends a scope prefix (disease/entity the claim is about) to each claim's sentence. These two NLI modes are evaluated on this synthetic dataset with \texttt{RelateConfig}, where \texttt{entailment\_threshold} and \texttt{contradiction\_threshold} are both set to $0.5$. The NLI model does not output SUPPORTING, CONTRADICTING, or UNRELATED labels, and only outputs entailment and contradiction probabilities; so an NLI output for a claim pair is considered SUPPORTING if it is above the \texttt{entailment\_threshold}; CONTRADICTING if above the \texttt{contradiction\_threshold}; and UNRELATED if the output is below both thresholds. These two thresholds are frozen: they are not tuned on the synthetic evaluation set, to keep the evaluation process out-of-sample.

The results in Table~\ref{tab:results-relation-classification-detailed} show that the NLI relation-classifier is strong with 0.927 accuracy under \texttt{predicate\_only} mode, and that SUPPORTING class is especially strong with 1.000 precision in both modes, and most errors occur on the boundary between UNRELATED and CONTRADICTING pairs. 

The \texttt{scope\_aware} mode performs marginally worse with a difference of $0.0034$ in accuracy, but it is the mode used in production, based on the assumption that it would help more ambiguous cases on real papers, where two claims might look similar on the surface, but are about different diseases or entities. A diagnostic joint sweep over (\texttt{entailment\_threshold} $\times$ 
\texttt{contradiction\_threshold}), both in ranges $\{0.4, 0.5, \dots, 0.9\}$ confirms that the result obtained with default, frozen thresholds at 0.5/0.5 is within a fraction of a percent of the optimum (entailment threshold~0.4, contradiction threshold~0.9: macro-F1 0.9307), so no further calibration for the two NLI thresholds was run, preserving the out-of-sample property of the evaluation set.

These results address RQ4. Both NLI components behave as designed: the grounding filter enforces source faithfulness, and the relation classifier is accurate on the class-balanced synthetic set of 300 claim-pairs. The cases in the synthetic set might be too unchallenging for the NLI model, so the attained result of $93\%$ accuracy is optimistic; classifying the cases encountered in production might be harder for the NLI model, as discussed in Subsection~\ref{subsec:eval-limitations}.
