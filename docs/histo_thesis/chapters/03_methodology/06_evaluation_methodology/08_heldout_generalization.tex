\subsection{Held-out generalization}\label{subsec:eval-heldout-generalization}

The held-out generalization test answers RQ5: whether the pipeline configuration (including the cascade) generalizes to papers it was never tuned on. It is run on a randomly selected subset of 15 papers, disjoint from the calibration cluster. The findings are scored using the same matcher and matching threshold as in the calibration cluster (Subsection~\ref{subsec:eval-knowledge-extraction}): no tuning, threshold adjustment, or model selection is performed on this held-out set. Therefore, the only intended difference is the set of papers. The held-out strict-F1 is reported in Section~\ref{section:results-generalization-to-heldout-papers}, alongside the in-sample calibration strict-F1; the difference between them is the generalization gap.

The test is evaluated against Opus-generated silver labels rather than expert annotations. It therefore measures whether the pipeline's performance transfers to the held-out set relative to this silver standard, not whether the silver standard itself is clinically correct or complete. This limitation is mentioned in Subsection~\ref{subsec:eval-limitations}.
