\subsection{Grounding and relation classification evaluation}\label{subsec:eval-grounding-and-relation-classification}

Two components of the knowledge-extraction pipeline use a shared biomedical natural-language-inference (NLI) model, described in Subsection~\ref{subsec:knowledge-grounding}, as their backbone: the grounding filter and the relation-classifier. The grounding filter scores how much a claim is entailed by the evidence paragraph it cites, whereas the relation-classifier in the RELATE stage scores pairs of rules or findings, and assigns them a SUPPORT, CONTRADICT, or UNRELATED label. The two components are evaluated separately, as they apply the shared backbone to different inputs. The evaluation procedure for the components is explained here; the corresponding empirical results are reported in Chapter~\ref{chapter:Results}.

\medskip{}

\textbf{Grounding filter.} The grounding filter is evaluated on the MAP findings emitted by the knowledge-extraction pipeline under the configuration calibrated on the calibration cluster of Subsection~\ref{subsec:knowledge-extraction-calibration-set}. The calibration process is explained in Section~\ref{section:results-abc-calibration}. For each finding, the NLI model emits an entailment score for the (finding claim, cited evidence) pair, where the cited evidence is retrieved from the database using the \texttt{te\_id} information in the finding.

Then, the grounding threshold is swept over $\{0.0, 0.1, \dots, 0.9\}$, and the surviving findings are scored against the Opus-generated silver-findings at each threshold value under the same matcher and metrics for the knowledge-extraction evaluation (Subsection~\ref{subsec:eval-knowledge-extraction}); therefore, the threshold sweep only changes the set of findings the grounding filter retains. The obtained retention rate results, as well as silver strict-F1, precision, and recall values, are reported in Chapter~\ref{chapter:Results}.

The purpose of the grounding threshold is to achieve source faithfulness, not to maximize silver-label agreement and strict-F1 scores. Strict-F1 measures agreement with the silver labeler Opus, whereas grounding measures how well a finding claim is entailed by its evidence. These are two related but distinct objectives: a claim can agree with the silver label while citing wrong evidence. To separate these two objectives, the evaluation reports strict-F1 scores for the different threshold values that are swept; the grounding threshold is set to 0.5 as a design decision to preserve source faithfulness. The sweep is run by offline replay on cached NLI scores (Subsection~\ref{subsec:eval-reprod-offline-replay}), eliminating the need to make extra API calls.

\medskip{}

\textbf{Relation classifier.} The RELATE stage outputs too few relations, especially too few contradictions; the emitted relations also do not have corresponding ground-truth relation labels. Therefore, the production output cannot be evaluated directly, nor can the per-class accuracy be reliably measured. 

In order to measure classifier performance, the synthetic 300-claim-pair set of Subsection~\ref{subsec:relation-classification-eval-set} is used -- balanced across SUPPORT / CONTRADICT / UNRELATED, and generated independently of the corpus, and of every calibration and evaluation set. 

The same NLI backbone scores each pair, but it does not emit labels; it outputs entailment and contradiction probabilities. These probabilities are mapped to a SUPPORT / CONTRADICT / UNRELATED label using the \texttt{RelateConfig} entailment and contradiction thresholds (Subsection~\ref{subsec:knowledge-relate}). The evaluation bypasses the structural comparability gate in the RELATE stage, allowing the NLI classifier to be isolated and its performance measured directly.

Two input modes are evaluated. In \texttt{predicate\_only} mode, the classifier scores the claim text only; \texttt{scope\_aware} mode prepends a compact scope tag to the text to be scored, adding contextual information about the disease or entity the claim refers to. Per-class precision, recall, F1, accuracy, and macro-F1 scores are measured and reported for both modes.

The entailment and contradiction thresholds are fixed to 0.5/0.5; the thresholds are not tuned on the synthetic evaluation set. A diagnostic joint sweep over the two thresholds, both with possible values in $\{0.4, 0.5, \dots, 0.9\}$, is run to check whether the performance of the chosen configuration is close to the optimum. As discussed in Subsection~\ref{subsec:eval-limitations}, results on this class-balanced synthetic set should be read as an optimistic accuracy estimate only for the NLI classifier.
