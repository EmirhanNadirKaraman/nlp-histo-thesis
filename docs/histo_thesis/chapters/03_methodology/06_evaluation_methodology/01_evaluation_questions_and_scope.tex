\subsection{Evaluation questions and scope}\label{subsec:eval-questions-and-scope}

Each of the five research questions maps to a different measurement procedure. Table~\ref{tab:research-questions} summarizes this mapping; each row is detailed in the section it points to. This section does not report empirical findings; its purpose is to define the evaluation design so the results in Chapter~\ref{chapter:Results} are interpretable: what is measured, the metrics that were used for scoring, how the datasets and the cases were sampled, and the offline-replay protocol used for cascade calibration and evaluation.
