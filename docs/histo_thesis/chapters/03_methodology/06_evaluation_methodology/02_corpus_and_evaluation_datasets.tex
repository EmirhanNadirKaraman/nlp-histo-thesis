\subsection{Evaluation datasets}\label{subsec:eval-datasets}

All evaluation datasets are derived from the 977-paper ingested corpus, whose acquisition, filtering, and ingestion are described in Subsection~\ref{subsec:ingestion-counts} and summarized in Table~\ref{tab:dataset-purpose-mapping}. Three paper subsets are drawn from the ingested corpus, and one synthetic dataset is generated; each of these is used for a different research question.

The \textbf{document-extraction evaluation set} is a 27-paper sample, manually and randomly selected from the ingested corpus, to cover diverse histopathology figure and table layouts. The exact papers are pinned, so that the selection is reproducible. It is disjoint from the knowledge-extraction subsets, in order to keep the different evaluation stages completely separate from each other. This subset is only used for the rubric-based figure and table extraction evaluation (RQ1, Subsection~\ref{subsec:eval-doc-extraction}).

The \textbf{knowledge-extraction calibration cluster} is a 15-paper subset of papers, selected by an integer-linear-programming relatedness selection of Subsection~\ref{subsec:eval-ilp}; its papers yield 454 knowledge-extraction source cases, and 2\,223 silver findings are extracted from these source cases by Claude Opus 4.7. This cluster is used to calibrate the knowledge-extraction thresholds and the agreement-based cascade, and to report the in-sample knowledge-extraction strict-F1 (RQ2) and cascade cost-quality results (RQ3).

The \textbf{held-out generalization set} is a separate subset consisting of 15 papers, drawn randomly from the corpus. It is held out from the calibration set, with silver findings generated in the same way: 285 source cases yielding 1\,657 silver findings. These findings are used for the \textbf{held-out generalization test} (RQ5, Subsection~\ref{subsec:eval-heldout-generalization}): the configuration fixed on the calibration cluster is replayed on the held-out set to measure whether the calibrated quality holds out-of-sample.

Relation classification is evaluated separately on a synthetic corpus generated by Claude Opus 4.7, consisting of 300 claim-pairs, labelled as supporting, contradicting, or unrelated. This dataset is not derived from the knowledge-extraction source cases, and is used to evaluate the relation classification only (RQ4, Subsection~\ref{subsec:eval-grounding-and-relation-classification}).
