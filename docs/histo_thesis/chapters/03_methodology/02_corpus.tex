This chapter defines the datasets over which the thesis system was built and evaluated. It describes the source corpus from which the histopathology papers are selected, the document extraction and ingestion process that converts those papers into structured document and text element objects. It also introduces the datasets used for replay-based evaluation, explains the silver-label scheme that scores the knowledge extraction outputs, and discusses the methodological limits of the chosen data design.
