This section defines the datasets over which the thesis system was built and evaluated. It describes the source corpus the histopathology papers are drawn from, and how those papers are ingested into structured document and text element records. It then introduces the calibration and evaluation subsets derived from that corpus, the silver-label scheme that scores the knowledge extraction outputs, and the methodological limits of the chosen data design.
