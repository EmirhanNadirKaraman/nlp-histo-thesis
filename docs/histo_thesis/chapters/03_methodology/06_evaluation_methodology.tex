This section defines how the empirical claims of the thesis are measured, and Chapter~\ref{chapter:Results} reports the results. The evaluation methodology is organized around five research questions, each of which is mapped to its measurement procedure and defining subsection in Subsection~\ref{subsec:eval-questions-and-scope}.

Four further subsections explain the evaluation methodology in more detail: how the calibration and evaluation datasets are constructed, in Subsection~\ref{subsec:eval-datasets}; how the calibration dataset is generated using integer linear programming, in Subsection~\ref{subsec:eval-ilp}; the offline-replay design that describes how cascade calibration works without making repeated API calls, in Subsection~\ref{subsec:eval-reprod-offline-replay}; and the methodological limits of the evaluation design in Subsection~\ref{subsec:eval-limitations}.
