\subsection{Provenance preserving storage}\label{subsec:doc-provenance-preserving-storage}

The pipeline persists its output in both database and file representations. For each paper, a relational database stores one \textbf{document} row, keyed by its PMC identifier, together with text elements, figures, tables, and cross-references that link text elements to the figures and tables they cite. Each text element stores the source document identifier, its section path, and its position within the section, so that the original document sequence can be reconstructed in the correct order. Alongside the database records, the figure and table crops, the assembled hierarchical text, and a manifest file for the media a paper contains, are written to disk for each paper. 

Persistence with stable IDs, instead of treating extraction as a one-shot preprocessing step, is important for two reasons. First, the knowledge-extraction pipeline references these stable identifiers in every \textit{Finding}'s evidence field, and in every \textit{CanonicalRule}'s representative pointer. Without stable IDs the provenance chain that allows to trace the source of a final scored rule back to its source evidence would not have been possible; if the elements were re-extracted in memory on each run, the provenance chain would not survive form one run to the next. Second, the rubric-scored evaluation of Section~\ref{section:Evaluation_Methodology} runs offline against the persisted media manifest files and cropped images, allowing extraction quality to be scored repeatedly without re-processing the original papers each time. 

The provenance chain preserves \textbf{traceability}, but does not prove clinical validity or correctness. The data stored in the database and files lets a reader trace a final scored rule back to its source paragraph from which it was inferred; it does not certify that the source content was correctly interpreted and a correct inference was made to create the final rule. The clinical validity and correctness of the entire system is bounded by the results in Chapter~\ref{chapter:Results}.
