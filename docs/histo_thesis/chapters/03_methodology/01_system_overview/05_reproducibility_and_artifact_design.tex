\subsection{Reproducibility and artifact design}

The system persists intermediate objects and execution artifacts into disk. These artifacts include the document database, the MAP voter cache, JSON summaries per paper, embedding caches used by the matcher and agreement scorer, and per-chunk cascade-decision and escalation logs. 

This design supports an \textbf{offline replay} of the evaluation; every numerical result for ablations and threshold calibrations is produced by a single driver that reads from the artifacts persisted in upstream stages, and re-derives the relevant metrics without invoking external models again, which saves API costs, while also eliminating potential non-deterministic behavior that would be caused by changing API outputs. Calibration sweeps over thresholds, scorer and agreement weights, and router policies run over the same artifacts.
