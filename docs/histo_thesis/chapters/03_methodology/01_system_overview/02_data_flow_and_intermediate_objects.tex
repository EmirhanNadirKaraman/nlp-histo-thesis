\subsection{Data flow and intermediate objects}\label{subsec:data-flow-and-intermediate-objects}

While data passes through the pipeline, it is converted to different typed intermediate objects, and each of these object types have their own database tables for observability. Every object has the information needed to trace it back to the previous stages in the pipeline; with this back-pointer information, each final rule can be traced back to its source paragraph and paper.

\begin{itemize}[label={}, leftmargin=1.5em, itemsep=0.4em]
    \item \textbf{Documents.} One row per ingested paper, with its PMC ID saved as a unique key in the database -- the root of the provenance chain that every later object points back to.

    \item \textbf{Text elements.} Paragraphs and headings, each with its unique path, content, depth and position within section. A text element points back to its document, and is the unit that the knowledge extraction pipeline consumes.
    
    \item \textbf{Figures and tables.} Cropped images of figures and tables identified in papers. Each of these figures and tables carries their caption and bounding box information, as well as cross-references where they are mentioned in text.

    \item \textbf{MAP findings.} The MAP stage generates an auditable summary of atomic biomedical claims for each chunk. Each MAP finding has a subject entity, outcome entity, relation, direction and more, as well as an evidence pointer, pointing back to the text element it was inferred from.

    \item \textbf{Normal findings.} The subject and outcome entities are resolved to their canonical names with a curated synonym dictionary and the UMLS linker, and then deduplicated. Normal findings record the findings they were merged from, to keep normalization reversible and the system traceable to its source text elements. 

    \item \textbf{Finding groups.} Normal findings are grouped by their subject, outcome, relation type and category. A finding group lists the normal findings it contains.

    \item \textbf{Canonical rules.} Finding groups are separated into different bins based on their directions. Per direction bin per finding group, a representative claim with the best grounding score is selected. The canonical rule keeps pointers to its group, to the normal findings it summarizes, and to the representative source text element, the paragraph from which the selected claim was drawn.

    \item \textbf{Relations.} Pairwise edges between canonical rules, each labelled SUPPORT, CONTRADICT or UNRELATED by an NLI cross-encoder. Only the supporting and contradicting pairs are kept. Each relation has the two canonical rules it connects, alongside the SUPPORT/CONTRADICT label, and the NLI confidence score.

    \item \textbf{Final rules.} Canonical rules are augmented with scores to generate final rules. A canonical rule is given a score between 0--1, combining its grounding score, the number of findings behind it, and the support and contradiction relations that touch it. The generated final rule keeps a pointer back to its canonical rule, closing the provenance chain, so that it can also be traced back to its source paragraph.
\end{itemize}

The detailed shape of each object is defined in Sections~\ref{section:Document_Extraction} and~\ref{section:Knowledge_Extraction}.
