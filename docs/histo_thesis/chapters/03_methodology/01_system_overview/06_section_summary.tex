\subsection{Section summary}\label{subsec:overview-section-summary}

This section described the \pinktodo {four-stage} pipeline that takes histopathology PMC OA papers, and produces structured, scored, and provenance-preserving final rule candidates. Document extraction, knowledge extraction, agreement-based cascading framework, and per-stage evaluation stages are separated from each other. Each subsystem has a bounded responsibility, and intermediate outputs are persisted so that evaluation can be replayed offline. 

The system considers separation of concerns, modularity, and provenance to be the architecture's main design constraints. This design supports auditability, which allows final rules to be traced back to the source evidence from the papers, error analysis, and offline inspection.
