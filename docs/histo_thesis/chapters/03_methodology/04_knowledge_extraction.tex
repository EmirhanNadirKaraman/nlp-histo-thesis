This section describes the knowledge extraction pipeline: the staged process that converts the text elements in \pinktodo{Section 3.3, Document extraction} to scored, structured rules with provenance. This section presents each stage in the pipeline: how sentence chunks are decomposed into atomic findings, then checked against their source texts, normalized, grouped, and canonicalized into rule candidates, related to each other, and finally, scored. Each stage produces an intermediate representation that is passed to the next stage, so that the generated final rules can be traced back to their source text elements. 

The focus of this chapter is to explain the purpose of each stage, the type of the objects each stage produces, and how provenance is preserved across the pipeline. Four topics are intentionally kept out of this chapter: the voter cascade that makes the MAP stage cost-aware (\pinktodo{Section 3.5, Agreement based cascading}), the evaluation protocol that supports the numerical claims (\pinktodo{Section 3.6, Evaluation methodology}), the results themselves (\pinktodo{Section 4, Results}), and the interpretation of these results (\pinktodo{Section 5, Discussion}).
