This section describes the knowledge extraction pipeline: the staged process that converts the text elements in Section~\ref{section:Document_Extraction} to scored, structured rules with provenance. This section presents each stage in the pipeline: how sentence chunks are decomposed into atomic findings, then checked against their source texts, normalized, grouped, and canonicalized into rule candidates, related to each other, and finally, scored. Each stage produces an intermediate representation that is passed to the next stage, so that the generated final rules can be traced back to their source text elements. 

The focus of this section is to explain the purpose of each stage, the type of the objects each stage produces, and how provenance is preserved across the pipeline. Four topics are intentionally kept out of this section: the voter cascade that makes the MAP stage cost-aware (Section~\ref{section:Agreement_Based_Cascading}), the evaluation protocol that supports the numerical claims (Section~\ref{section:Evaluation_Methodology}), the results themselves (Chapter~\ref{chapter:Results}), and the interpretation of these results (Chapter~\ref{chapter:Discussion}).
