\section{Agreement-Based Cascading}\label{section:Agreement_Based_Cascading}

\makeatletter

\makeatother

This section describes agreement-based cascading, the framework used to make the MAP stage of Subsection~\ref{subsec:knowledge-map} cost-aware. This framework turns the MAP stage from a single language-model call into a tiered voter ensemble with explicit agreement and escalation policies. Cheap voters are queried first. An agreement scorer then measures consensus among the voters; the resulting score drives the escalation policy, which decides whether to accept the output, reject it, or escalate it to the next layer with more powerful, but also more expensive, language models. 

This section first introduces the three-tier voter structure. It defines the agreement scorer, used to quantify the consensus between the output of different voter models. Then, it describes the escalation policy: the policy that determines whether to accept, escalate, or reject the output of the models in a tier, based on the agreement score. Later, this section introduces two routing gates that can override the default escalation policy: a polarity-conflict gate, which forces escalation when voters disagree on claim polarity; and a schema and provenance checker that verifies the structural and provenance validity of the voter outputs. Finally, this section describes the offline calibration procedure, with which the production scorer and thresholds were tuned. 

The evaluation protocol for agreement-based cascading is defined in Section~\ref{section:Evaluation_Methodology}; the empirical results are reported in Chapter~\ref{chapter:Results}, and discussed in Chapter~\ref{chapter:Discussion}.
