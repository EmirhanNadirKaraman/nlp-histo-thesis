\subsection{Motivation}\label{subsec:abc-motivation}

LLM-based extraction faces a cost-quality trade-off. 

Running the strongest available model on every input is accurate but expensive, whereas running a cheaper model on every input is more affordable but less reliable on difficult or ambiguous cases. A cascade system mitigates this trade-off: cheaper models are used when possible, and stronger models are used when they are needed~\parencite{chen2024frugalgpt}. The main design problem is this: how should the system decide, for each input, whether the cheap output is good enough to accept, or the input should be escalated to a stronger and more expensive tier.

Agreement-based cascading uses inter-voter agreement between cheap voters as a routing signal. Three cheap voters are run in parallel on the same input. When these independent voters agree, the input is treated as straightforward, so the cascade accepts the cheap-tier result. When they disagree, the input is treated as ambiguous, and is escalated to a stronger and costlier tier.

Agreement-based cascading is not presented here as a novel cascading paradigm. Its name and training-free design follow prior work on agreement-based cascading~\parencite{kolawole2025abc}; the idea of using agreement as the routing signal connects it to self-consistency voting~\parencite{wang2023selfconsistency} and to a wider family of ensemble-agreement methods, including semantic agreement~\parencite{soiffer2025semantic}. The contribution of this section is the calibrated, provenance-aware integration of agreement-based cascading into the histopathology knowledge-extraction pipeline described in Section~\ref{section:Knowledge_Extraction}, together with the safety gates of Subsection~\ref{subsec:abc-safety-gates}, and the offline calibration protocol of Subsection~\ref{subsec:abc-calibration-and-replay}, which selects the production scorer and the thresholds.
