\subsection{Calibration and replay}\label{subsec:abc-calibration-and-replay}

There are three groups of calibration parameters in the cascade: the agreement scorer and its weights, described in Subsection~\ref{subsec:abc-agreement-scoring}; the threshold pair $(\theta, \theta_{\mathrm{reject}})$ of Subsection~\ref{subsec:abc-accept-reject-escalate}; and the safety gates of Subsection~\ref{subsec:abc-safety-gates}. These parameters are calibrated on the calibration dataset, through an offline-replay protocol. The agreement scorer and thresholds are swept jointly, whereas safety-gate flags are evaluated through ablations. 

The replay protocol is designed based on one observation: once we collect voter outputs once, changes to the agreement scorer, thresholds, or safety policies can be evaluated offline, without having to make further LLM calls. The voter outputs are cached: the cache records the \texttt{AuditableSummary} output of each voter at each cascade tier, for each chunk. Thus, any possible escalation path can be replayed offline.

After collecting each voter output, the calibration becomes a deterministic replay problem. Using the cached voter outputs, joint sweeps over $(\text{agreement scorer}, \theta, \theta_{\mathrm{reject}})$ and ablations of the safety flags are run. Subsection~\ref{subsec:eval-abc} defines the calibration grid, and Chapter~\ref{chapter:Results} reports the strict-F1 scores for the different configurations of the cascade thresholds and options.

The offline replay protocol has important reproducibility consequences. It removes external API calls from the calibration loop; once the primer cache has been generated, the calibration process becomes fully offline, quick, and cheap. This cache design, however, constrains calibrations to the configurations the cache can support: changes in the voter pool, model identifiers, model temperatures, or MAP prompts invalidate the cache, and a fresh pass of LLM calls is required. This protocol, therefore, trades flexibility for reproducibility: calibration is cheap and replayable as long as the voter pool, voter settings and prompts are unchanged.
