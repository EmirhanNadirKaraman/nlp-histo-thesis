\subsection{Relation classification evaluation set}\label{subsec:relation-classification-eval-set}

\pinktodo{Generate a 300 claim-pair dataset to evaluate the relation classification.}

The relation classification component uses the NLI classifier in the knowledge-extraction pipeline to label claim pairs as \emph{supporting}, \emph{contradicting}, or \emph{unrelated} to each other. This component is evaluated on a separate set, consisting of 300 labelled claim-pairs, instead of depending on the outputs produced by RELATE, over the corpus. Since the rules generated over the corpus do not have ground-truth relation labels, the relation outputs can only be compared and analyzed indirectly, through relation counts and label stability across different configurations of the component, as described in Subsection~\ref{subsec:eval-grounding-and-relation-classification}. Therefore, a labelled dataset is required, to measure relation-classification directly.

300 claim-pairs are generated by Opus 4.7 at temperature zero, across a range of histopathology topics. Each claim pair is generated from an intended relation label: SUPPORTING, CONTRADICTING, or UNRELATED. Then, the output of the relation classifier is compared and scored against the silver reference label. The dataset is built independently of the ingested corpus, calibration and other evaluation datasets, and is not sampled from pipeline-extracted rules.

This dataset only evaluates the relation-classification stage, it does not evaluate the entire knowledge-extraction pipeline. Full knowledge-extraction evaluation is done separately on the set of Subsection~\ref{subsec:knowledge-extraction-eval-set}, the procedure for which is described in Subsection~\ref{subsec:eval-grounding-and-relation-classification}. No threshold or hyperparameter is tuned on the claim-pair dataset, so it provides out-of-sample measurements. 

Since the claim pairs are synthetically constructed, the relations between them might be cleaner than the claim pairs in the corpus: a claim pair with a contradicting label might have a very obvious contradiction, supporting claims might be too similar, and unrelated claim pairs might be more plainly unrelated. Therefore, the accuracy metrics achieved on this synthetic dataset might over-state performance, compared to when running the relation classification on the corpus. This limitation is discussed in Chapter~\ref{chapter:Discussion}.
