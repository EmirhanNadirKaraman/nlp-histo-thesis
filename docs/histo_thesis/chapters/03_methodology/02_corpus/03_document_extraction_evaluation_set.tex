\subsection{Document extraction evaluation set}

The document-extraction evaluation set consists of 27 PDFs, manually and randomly sampled from the ingested corpus, and the selection of PDF files is frozen for reproducibility. This subset of papers is only used for the rubric-based evaluation of the table/figure extraction, described in \pinktodo{Chapter 8, §8.3}, and the corresponding results are in \pinktodo{Chapter 9.}

Each PDF was manually annotated according to a four-dimensional rubric described in \pinktodo{Chapter 8, Section §8.3.} The rubric covers figure crops, table crops, captions, and masks. These annotations produce the labels that \pinktodo{Chapter 9, Section §9.1} calculates strict-F1 scores against. This chapter does not report the scores themselves; the results are reported in \pinktodo{Chapter 9.} 

The size of the 27-PDF subset is a methodological limitation. It is sufficient to show the figure and table extraction evaluation performed in this thesis, but stronger claims cannot be made across the full range of different biomedical paper layouts. Extending the annotation dataset with a larger sample would be the natural next step for further analysis.
