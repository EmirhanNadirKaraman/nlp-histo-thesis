\subsection{Document extraction evaluation set}\label{subsec:doc-extraction-eval-set}

The document-extraction evaluation set consists of 27 PDFs, manually selected from the ingested corpus; the selection of PDF files is frozen for reproducibility. This subset of papers is only used for the rubric-based evaluation of the table/figure extraction, described in Subsection~\ref{subsec:eval-doc-extraction}.

Each PDF was manually annotated according to the four-dimensional rubric (crop, caption, footnote, mask) defined in Subsection~\ref{subsec:eval-doc-extraction}. These annotations produce the labels that Section~\ref{section:results-doc-extraction-performance} calculates strict-F1 scores against. The results are not reported in this section, but in Chapter~\ref{chapter:Results}.

The size of the 27-PDF subset is a methodological limitation. It is sufficient to show the evaluation of figure and table extraction, but stronger claims cannot be made across the full range of biomedical paper layouts. Extending the annotation dataset with a larger sample would be the natural next step for further analysis.
