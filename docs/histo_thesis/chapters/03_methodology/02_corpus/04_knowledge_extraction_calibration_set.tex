\subsection{Knowledge extraction calibration set}\label{subsec:knowledge-extraction-calibration-set}

The knowledge-extraction \pinktodo{calibration} dataset consists of 273 source cases drawn from the 15-paper calibration dataset, generated by an ILP algorithm based on relatedness of papers; the algorithm is explained in Subsection~\ref{subsec:eval-ilp}. With the relatedness algorithm, we find the papers, on which the knowledge extraction pipeline is most likely to generate supporting and contradicting claims. This subset of papers is used to calibrate thresholds in the pipeline, explained in detail in Subsection~\ref{subsec:abc-calibration-and-replay}.

Each source case corresponds to one MAP-stage chunk from a paper. These cases are used to calibrate the knowledge-extraction pipeline thresholds, including the agreement-based cascading framework. The 273 source cases derived from this 15-paper subset are the main inputs used for calibration and the framework comparison in the knowledge-extraction stages.
