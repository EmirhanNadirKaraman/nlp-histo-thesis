\subsection{Knowledge extraction calibration set}\label{subsec:knowledge-extraction-calibration-set}

The knowledge-extraction calibration set consists of 454 source cases derived from a 15-paper cluster, selected by an integer linear programming (ILP) algorithm based on the entity-relatedness of papers. The algorithm is explained in Subsection~\ref{subsec:eval-ilp}. Choosing mutually related papers increases the likelihood that the knowledge extraction pipeline generates supporting and contradictory claims across papers, providing a signal for cross-paper relation analysis. Each source case corresponds to one MAP-stage chunk (one usable paragraph) from a paper. These 454 cases serve as the main input for calibrating the knowledge-extraction pipeline thresholds, including the agreement-based cascading framework, and for comparing agreement scorers, as detailed in Subsection~\ref{subsec:abc-calibration-and-replay}.
