\subsection{Knowledge extraction calibration set}\label{subsec:knowledge-extraction-calibration-set}

The knowledge-extraction calibration set consists of 454 source cases derived from a 15-paper cluster; this cluster is selected by an integer linear programming (ILP) algorithm based on entity-relatedness of papers. The algorithm is explained in Subsection~\ref{subsec:eval-ilp}. Choosing mutually related papers increases the chance that the knowledge extraction pipeline generates supporting and contradicting claims across papers, giving the cross-paper relation analysis signal. Each source case corresponds to one MAP-stage chunk (one usable paragraph) from a paper. These 454 cases are the main input for calibrating the knowledge-extraction pipeline thresholds, including the agreement-based cascading framework, and for comparing the agreement scorers, as detailed in Subsection~\ref{subsec:abc-calibration-and-replay}.
