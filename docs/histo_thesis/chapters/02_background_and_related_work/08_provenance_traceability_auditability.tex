\section{Provenance, traceability, and auditability}\label{section:background-provenance-traceability-and-auditability}

Each entry should be traceable to the evidence it was produced from, for a clinical knowledge base to be considered trustworthy. Therefore, provenance is a core requirement for the thesis. Work on data and machine-learning provenance, as well as more recent work on attribution and citation of LLM outputs, argues that the source links should be recorded during output generation time, rather than reconstructed later~\parencite{}. 

This thesis follows this principle: it records source spans, page coordinates, and paragraph paths, so that each figure, table, or final rule can be traced back to its origin (Sections~\ref{section:Document_Extraction} and~\ref{section:Knowledge_Extraction}). Because traceability is a structural property of the pipeline rather than a quality estimate, Section~\ref{section:results-ke-pipeline-output-and-provenance} reports it as a provenance carry-rate; Section~\ref{section:disc-doc-extraction-and-provenance} then argues that coordinates and source paths that a pipeline discards at extraction time cannot be recovered afterward.
