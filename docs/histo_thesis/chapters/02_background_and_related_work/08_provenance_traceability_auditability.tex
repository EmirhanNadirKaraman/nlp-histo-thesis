\section{Provenance, traceability, and auditability}\label{section:background-provenance-traceability-and-auditability}

Each entry should be traceable to the evidence it was produced from, for a clinical knowledge base to be considered trustworthy. Therefore, provenance is a core requirement for the thesis. Work on data and machine-learning provenance, as well as more recent work on attribution and citation of LLM outputs, argues that the source links should be recorded during output generation time, rather than reconstructed later~\parencite{}. 

This thesis follows this principle: it records source spans, page coordinates, and paragraph paths, so that each figure, table, or final rule can be traced back to its original source, preserving provenance throughout the pipeline by design, as explained in Sections~\ref{section:Document_Extraction} and~\ref{section:Knowledge_Extraction}). Chapter~\ref{chapter:Results} reports the provenance carry-rate results as it is a structural property of the pipeline. Later, Chapter~\ref{chapter:Discussion} argues that provenance built into the pipeline from the first stage of the pipeline is exactly what free-form generated claims cannot reliably add in a post-processing step.
