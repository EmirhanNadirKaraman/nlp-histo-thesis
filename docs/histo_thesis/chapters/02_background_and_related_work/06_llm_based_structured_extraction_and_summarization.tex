\section{LLM-based structured extraction and summarization}\label{section:background-llm-based-structured-extraction-and-summarization}

Large language models are increasingly used to read text and emit structured outputs under a predefined schema, which is the mechanism used in the MAP stage of this thesis. Two properties of LLM-based extraction are important for the pipeline design.

First, a single LLM call is not reliable enough by itself, and its output should be checked, as it may hallucinate, paraphrase evidence too freely, or produce different outputs across runs~\parencite{huang2025surveyhallucinationlarge}. For these reasons, agreement-based strategies such as self-consistency are used in the literature, where multiple output generations are collected and reconciled into a more reliable output~\parencite{wang2022selfconsistency}. This thesis generalizes this idea by extending repeated output generation from the same model to cross-provider voting, via the agreement-based cascading mechanism of Section~\ref{section:Agreement_Based_Cascading}. Two further families of reliability techniques are not used here. Chain-of-thought prompting, for example, can make multi-step extraction more reliable by introducing intermediate reasoning steps~\parencite{wei2022chainofthoughtpromptingelicits}, but this pipeline does not elicit such reasoning, and no reasoning trace is ever treated as evidence; instead, it relies only on the verbatim source spans stored with each finding to support grounding and provenance (§\ref{section:Knowledge_Extraction}). A related line of work repairs unreliable LLM outputs, either by using a different LLM to correct the existing output~\parencite{zhong2024harnessinglargelanguage}, or by editing the claim until a fact-verification model scores it as supported~\parencite{chen2023convergetruthfactual}. In contrast, this thesis reconciles outputs using cross-provider agreement rather than by repair. An entailment model does score each claim against its evidence, but only to filter, so unsupported claims are dropped rather than rewritten.

Second, output granularity determines how effectively the extracted information can be verified: free-text summaries merge multiple claims, making it harder to trace them back to their evidence, whereas typed, atomic findings remain individually groundable and auditable. This thesis therefore emits atomic findings rather than a summarization-style consolidation of free-form text, as detailed in Section~\ref{section:Knowledge_Extraction}.
