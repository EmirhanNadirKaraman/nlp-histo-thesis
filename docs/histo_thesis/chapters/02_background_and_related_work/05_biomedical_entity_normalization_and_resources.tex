\section{Biomedical entity normalization and resources}\label{section:background-biomedical-entity-normalization-and-resources}

Papers use different terminology for the same concepts, and a normalization process is necessary for the pipeline to be able to compare findings across papers. This is the task of biomedical entity normalization: it maps surface forms that occur in papers' text to a controlled vocabulary. This thesis combines scispaCy biomedical models~\parencite{} with Unified Medical Language System (UMLS)~\parencite{} to assign concept identifiers (CUIs) to subject and outcome entities. Normalized string matching is used as a fallback, when no reliable CUI could be found, as described in Section~\ref{section:Knowledge_Extraction}. 

These CUIs make the later stages in the pipeline, namely the grouping, the cross-paper comparability gate, and the canonicalization of rules well-defined. Findings that use different wording, but refer to the same UMLS concepts can be grouped together; the cross-paper comparability gate and the rule canonicalization stage are supported by the same mechanism, giving the pipeline a stable way to decide when two findings are about the same entity. The UMLS-derived entity buckets also drive the paper selection in the calibration cluster, which uses integer linear programming (Section~\ref{eval-ilp}). Alternative biomedical linkers and an evaluation benchmark exist~\parencite{}, but the scispaCy/UMLS stack was found to be enough for the needs of this thesis.
