\section{Grounding, entailment, and NLI}\label{section:background-grounding-entailment-and-nli}

Checking whether a claim is supported by the evidence it cites can be formulated as a natural-language-inference (NLI) problem: does the evidence paragraph entail the claim? This thesis addresses it with a frozen biomedical NLI cross-encoder, \texttt{PubMedBERT-MNLI-MedNLI}~\parencite{deka2023pubmedbertextended}, based on PubMedBERT~\parencite{gu2021biomedbert}, fine-tuned on the MNLI~\parencite{williams2018mnli} and MedNLI~\parencite{romanov2018mednli} entailment datasets. Biomedical entailment is a difficult task by itself: on BioNLI, neural classifiers only reach F1 scores in the mid-70s~\parencite{bastan2022bionligeneratingbiomedical}. This is the main motivation behind using a domain-specific NLI model rather than a general-purpose one.

The same NLI model is used in two different roles in the thesis pipeline: as a grounding filter and as a relation classifier. The grounding filter scores each (claim, evidence) pair and drops findings that are not sufficiently supported by their evidence; the relation classifier scores the entailment and contradiction of each candidate rule pair, and assigns a \texttt{SUPPORT} / \texttt{CONTRADICT} / \texttt{UNRELATED} label to each of these pairs; the label assignment logic is described in Section~\ref{section:Knowledge_Extraction}. The use of entailment scores as a faithfulness check connects the thesis to other work on detecting unsupported or hallucinated content by comparing generated claims against evidence~\parencite{honovich2022truereevaluatingfactual, rashkin2023measuringattributionnatural, huang2025surveyhallucinationlarge}. Entailment has also been used for biomedical relation extraction, formulating relation extraction as a textual entailment (NLI) task by expressing each relation class as a class-indicative hypothesis, reporting large gains on biomedical benchmarks such as BioRED~\parencite{hogan2025entangledrelationsleveraging}; the relation classifier in this thesis instead compares two rules extracted earlier in the pipeline against each other, so the relation it emits for a rule pair expresses whether they agree, disagree, or are unrelated.

The contribution is empirical: an off-the-shelf biomedical NLI model with frozen thresholds is shown to perform well enough for both source faithfulness and relation classification, with results reported in Section~\ref{section:results-nli-in-grounding-and-relation-classification}.
