\section{Cost-aware LLM inference and cascading}\label{section:background-cost-aware-llm-inference-and-cascading}

Using the strongest models for all inputs can improve quality, but is prohibitively expensive for large-scale knowledge-extraction. This is the main motivation behind cost-aware inference strategies that send easier cases to cheaper models, and reserve expensive models for more difficult cases~\parencite{chen2024frugalgpt}. 

The MAP-stage in this thesis follows this idea by incorporating agreement-based cascading into the pipeline, in which the agreement between cheaper voters decides whether to escalate text chunks to a more expensive voter tier, accept the cheaper output, or reject it completely. This configuration builds directly on agreement-based cascading for efficient inference~\parencite{kolawole2025abc} and on semantic-agreement cascades for free-prose output~\parencite{soiffer2025semantic}.

This thesis implements a variant that scores agreement over structured, typed findings rather than free-form prose, adds safety gates for supporting or conflicting outputs from different models, and uses voter models from multiple providers. The cascade is calibrated on the selected histopathology corpus, and Chapter~\ref{chapter:Results} reports that, under an Opus-based silver metric for cost-quality, the cascade is not cost-justified against the single-model Sonnet baseline, even though it significantly outperforms cheaper models.
