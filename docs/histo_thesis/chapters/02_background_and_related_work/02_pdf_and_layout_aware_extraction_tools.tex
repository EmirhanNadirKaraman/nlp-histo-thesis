\section{PDF and layout-aware extraction tools}\label{section:background-pdf-and-layout-aware-extraction-tools}

Several tools exist for converting scientific PDFs into structured representations, ranging from rule-based parsers to layout-aware neural models, and recent document-conversion systems that work end-to-end~\parencite{}. This thesis uses Docling as the main structural backbone of the document-extraction stage~\parencite{}. Docling is suitable for this role because it outputs typed objects, such as text blocks, headings, figures, and tables, each with its bounding box. The section hierarchy and the reading order are reconstructed from this output. 

Several post-processing stages on top of Docling improve output quality; they are described in Section~\ref{section:Document_Extraction}, and their contribution is measured against the off-the-shelf Docling baseline in Section~\ref{section:disc-doc-extraction-and-provenance}. Several other converters were examined, including Nougat, Marker, PDFFigures2, and PyMuPDF4LLM; but these alternatives were not selected for production~\parencite{}.
