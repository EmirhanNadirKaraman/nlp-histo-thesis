\section{PDF and layout-aware extraction tools}\label{section:background-pdf-and-layout-aware-extraction-tools}

Several tools exist for converting scientific PDFs into structured representations, ranging from rule-based parsers to layout-aware neural models, and recent document-conversion systems that work end-to-end~\parencite{ramakrishnan2012layoutawaretextextraction, auer2024doclingtechnicalreport, blecher2023nougatneuraloptical, wang2024docllmlayoutawaregenerative}. This thesis uses Docling as the main structural backbone of the document-extraction stage~\parencite{auer2024doclingtechnicalreport}. Docling is suitable for this role because it outputs typed objects, such as text blocks, headings, figures, and tables, each with its bounding box. The section hierarchy and the reading order are reconstructed from this output. An alternative approach to layout-aware extraction is to use end-to-end OCR-free models that process rendered page images directly. The Donut document-understanding transformer~\parencite{kim2022ocrfreedocumentunderstanding} and the multi-page vision-language model mPLUG-DocOwl2~\parencite{hu2025mplugdocowl2highresolutioncompressing} are examples of models that follow this approach. The thesis does not adopt these models, because the pipeline requires token-level bounding boxes to link extracted claims to the precise location of source evidence.

Several post-processing stages on top of Docling improve output quality; they are described in Section~\ref{section:Document_Extraction}, and their contribution is measured against the off-the-shelf Docling baseline in Section~\ref{section:results-doc-extraction-performance}. Several other converters were examined, including Nougat~\parencite{blecher2023nougatneuraloptical}, Marker~\parencite{paruchuri2024marker}, PDFFigures2~\parencite{clark2016pdffigures2}, and PyMuPDF4LLM~\parencite{artifex2024pymupdf4llm}; but these alternatives were not selected for production.
