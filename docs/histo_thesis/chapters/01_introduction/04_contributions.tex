\section{Contributions}\label{section:intro-contributions}

This thesis makes six contributions, detailed in Chapter~\ref{chapter:Conclusion_and_Future_Work}. 

First, it develops an end-to-end extraction pipeline that turns histopathology PDFs into a structured clinical knowledge base, in which each figure, table, and rule can be traced back to where it was derived from, including source page, span, and page coordinates. Provenance is built-in, rather than reconstructed after extraction, so traceability is structurally guaranteed~\parencite{}. 

Second, it implements a document-extraction stage comprising a hybrid table detector~\parencite{}, a footnote expansion component, a geometric caption matcher and a two-pass text filter, substantially raising the table and figure strict-F1 performance, compared to an off-the-shelf baseline. Every significant gain is attributed to a specific post-processing step, reported in Section~\ref{section:intro-summary-of-findings}. 

Third, the agreement-based cascading framework~\parencite{} is adapted to the use case of the thesis: typed biomedical extraction outputs. The development of the framework used in the MAP-stage of the knowledge-extraction pipeline includes calibration, a multi-provider voter pool with a three-tier cascade structure, and safety gates; the safety gates handle single-voter cases (when only one voter in a tier emits valid results) and polarity conflicts between voters. This design builds on and extends agreement-based cascading~\parencite{}, self-consistency voting~\parencite{}, and semantic agreement scoring~\parencite{}; and applies them to schema-constrained and typed extraction, rather than to free-form text. 

Fourth, it provides methodology for reproducible calibration and evaluation. The calibration and evaluation use an ILP-selected calibration cluster, consisting of 15 papers that are related at the entity level; furthermore, the evaluation uses model-generated silver labels, a matcher-based strict-F1, a cost-quality frontier with economy, knee, and quality operating points, and an offline-replay protocol. Voter outputs and NLI scores are cached, making it possible to reproduce every result from these cached artifacts, without further API calls. 

Fifth, it reuses a frozen biomedical NLI model~\parencite{gu2021biomedbert, williams2018mnli, romanov2018mednli} for grounding and relation classification tasks. The thesis evaluates whether the PubMedBERT-based NLI model is sufficient in both roles. 

Sixth, it defines frozen evaluation datasets: a document-extraction rubric set, the calibration and held-out clusters, and a synthetic dataset for relation classification. All of these datasets are fixed, so the results of the experiments are reproducible.

The lasting contribution of the thesis is the entire framework, which can be re-calibrated for a different corpus, budget, or quality target.
