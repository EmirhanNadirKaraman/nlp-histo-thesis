\section{Contributions}\label{section:intro-contributions}

The thesis makes six contributions, which are developed in the chapters that follow, and enumerated in full in Section~\ref{section:contributions}: an end-to-end, provenance-preserving extraction pipeline; a document-extraction stage whose gains are measured against an off-the-shelf baseline; an agreement-based cascade adapted to typed, schema-constrained biomedical extraction; a methodology for reproducible calibration and evaluation; a shared, frozen NLI backbone used for grounding and relation classification; and a set of frozen evaluation datasets. Their lasting value is the framework itself, which can be recalibrated for a different corpus, budget, or quality target.
