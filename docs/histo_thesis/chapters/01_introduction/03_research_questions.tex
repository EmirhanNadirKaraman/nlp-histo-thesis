\section{Research questions}\label{section:intro-research-questions}

This thesis is structured around five research questions, listed in Table~\ref{tab:research-questions} and evaluated in Chapter~\ref{chapter:Results}. Each is answered with concrete, quantitative measurements. 

\begin{itemize}[label={},leftmargin=1.5em]

    \item \textbf{RQ1 -- Document extraction.} How faithfully does the document-extraction pipeline recover the text, tables, figures, captions, and related layout information from the papers? This question also asks how much improvement the proposed pipeline provides over the off-the-shelf document-extractor baseline; measurements are made using a hand-annotated rubric across a set of papers.
    
    \item \textbf{RQ2 -- Knowledge extraction and provenance.} What is the quality of the extracted findings and rules against strong-model-generated silver labels, and is provenance preserved end-to-end for every extracted figure, table, and rule?
    
    \item \textbf{RQ3 -- Cost-quality trade-off.} Is the agreement-based cascade worth its cost, relative to sending each text chunk to a single strong model?
    
    \item \textbf{RQ4 -- Grounding and relation classification.} How does the shared biomedical NLI model~\parencite{gu2021biomedbert} perform in its grounding and relation classification roles?
    
    \item \textbf{RQ5 -- Held-out generalization.} Does the performance of the configuration calibrated on one set of papers generalize to a held-out set, or does it overfit to the calibration cluster?

\end{itemize}

One methodological caveat affects RQ2-RQ5. Their silver metrics depend on silver labels generated by a strong LLM, so the resulting scores measure agreement with the labeler, not ground truth -- following recent work that assesses systems against another model's labels~\parencite{}. This caveat is revisited as the main validity threat in Section~\ref{section:disc-threats-to-validity}.
