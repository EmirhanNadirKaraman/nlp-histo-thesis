\section{Problem statement}\label{section:intro-problem-statement}

The components to build an auditable clinical knowledge base already exist, but mostly in isolation. Layout-aware tools can reconstruct the logical structure of scientific PDFs~\parencite{ramakrishnan2012layoutawaretextextraction, wang2024detectorderconstructtreeconstruction}; dedicated models can detect tables and figures in PDFs, which often contain substantial evidence in histopathology papers~\parencite{smock2022pubtables1mcomprehensivetable, clark2015extractingfigurestables}; biomedical entity-normalization tools can map entities in different surface forms to shared concepts, so that findings across papers can be compared~\parencite{neumann2019scispacy, bodenreider2004umls}; LLMs can perform structured extraction, and existing literature on the topic studies how to make the process cheaper to run, through cascading and routing mechanisms across multiple models~\parencite{chen2023frugalgpt, kolawole2025abc, soiffer2025semantic}. Tracking the source of a piece of data to preserve provenance is also well established~\parencite{simmhan2005surveydataprovenance}. 

The problem is that these components are rarely combined into a single pipeline under a demanding cost-quality constraint; each has its own benchmarks and its own definition of success. The objective of this thesis is more ambitious than evaluating its parts in isolation; it builds a pipeline that preserves complete provenance for all of its outputs while remaining economically feasible. 

This thesis asks where off-the-shelf tools already suffice, where calibrated agreement and grounding improve the results, and where they justify their cost.

The scope of this thesis is bounded; the system targets open-access histopathology papers in English and is designed to emit a set of candidate clinical rules that will be reviewed and validated by experts. Its confidence scores should not be treated as clinical probabilities.
