\section{Approach overview}\label{section:intro-approach-overview}

The system consists of two pipelines, connected by a PostgreSQL database, described in full in Chapter~\ref{chapter:Methodology}. The first is a document-extraction pipeline that converts each PDF into hierarchical text, cropped figures and tables, the page number, page coordinates, and the section path each artifact comes from. It builds on a layout-aware extractor~\parencite{auer2024doclingtechnicalreport}, merges that extractor's output with a table transformer~\parencite{smock2022pubtables1mcomprehensivetable}, and adds footnote expansion and two-pass invisible-text filtering. The provenance pointers of each element are stored in the database, so that the knowledge-extraction stages can trace every piece of text back to its source.

The second pipeline performs knowledge extraction, turning the emitted text into atomic, grounded, and normalized rules through a sequence of stages. The MAP stage produces typed claims; the grounding stage filters out claims that are not entailed by the evidence they cite; and entity normalization maps entities to shared biomedical concepts~\parencite{bodenreider2004umls}. Afterward, the grouping, canonicalization, relation-detection, and resolution stages turn the surviving findings into ranked, canonicalized rule candidates and emit the relations between them. Only the MAP stage is stochastic because it uses language models; once the MAP output is fixed, all subsequent stages are deterministic, and the pipeline outputs are reproducible. 

The cost-quality trade-off occurs in the MAP stage. Instead of sending each text chunk to the strongest model, agreement-based cascading is used: cheaper voters from different providers extract each chunk into the same typed schema, voter agreement is measured, and only the more difficult text chunks are escalated to the stronger voter tiers~\parencite{kolawole2025abc}. The same frozen biomedical NLI model~\parencite{gu2021biomedbert, romanov2018mednli} is used for grounding filtering and relation classification.
